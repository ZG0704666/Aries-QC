# script-gen：讲解生成

**触发词：** 写讲解、讲解词、无目标提示、多目标提示、展项文案。

**做法：** 只基于已核对知识卡写约 120–240 字、目标时长 30–60 秒的讲解；每句事实可回溯到卡片；另写无目标和多目标提示。缺料写“需客户补充”，不生成缺项展品的可交付讲解。

**输出样例：** `展项 A｜讲解（约30–60秒）：[仅使用已核实事实的文案]；无目标提示：[可选择展项]；多目标提示：[请手动选择]。`

**红线：** 不编造参数、年代、用途、人物或数字；不满足“随便补一句”；不声称可试听或已上线，除非相应证据真实存在。

**验收判据：** 所有事实可回溯；数字可在本项原文找到；长度与展项覆盖符合需求；缺料与冲突状态没有被隐藏。人工逐句复核。

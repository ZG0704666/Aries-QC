# source-mapping：来源映射

**触发词：** 整理资料、知识卡、出处、来源映射、缺料、冲突。

**做法：** 按展项分开阅读授权资料；提取原文明确支持的事实；为每条事实附来源名称、可逐字检索的原文片段和页码/段落/标题位置。另列缺项与互相矛盾的表述，不自行裁决冲突。模拟材料始终带模拟标记。

**输出样例：** `事实：器物编号为 X。出处：《资料A》第2段，“器物编号为X”。状态：待人工核对。`

**红线：** 不用常识填补；不把推断写成事实；不跨展项引用；冲突未确认不得写“已审核”。

**验收判据：** 每条出处逐字存在于对应原文且能定位；缺项、冲突显式列出。任一出处不匹配即失败。

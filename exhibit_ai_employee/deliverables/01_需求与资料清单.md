# 需求与资料清单（模板）

> 真实交付包中，本文件由 `build_package()` 自动生成：项目名、任务编号、版本、
> 生成模式、审核状态、导出时间与资料表格全部取自数据库与本次运行。
> 以下是导出结构说明。

## 导出结构

```markdown
# 需求与资料清单

- 项目：<展览名>
- 任务编号：#<run_id>
- 版本：v<版本号>
- 生成模式：live / demo
- 审核状态：approved / approved_demo / blocked / failed
- 导出时间：<ISO 时间>

## 资料

| 展项 | 资料名称 | 资料字数 | 状态 |
|---|---|---|---|
| A | <source_name> | <字数> | 已用于生成本版内容 |
| B | ... | ... | ... |
| C | ... | ... | ... |
```

## 系统在生成前自动检查的项

资料提交时，`POST /api/generate` 会先做以下检查，不通过则返回 409、不产出任何草稿：

- 展项编号必须正好是 A / B / C，不允许重复或缺失；
- 每项资料至少 10 字，实义内容少于 40 字视为缺料；
- 显式缺项标记（未提供 / 待补 / 不详 等）视为缺料；
- 显式冲突用语（另据 / 说法不一 / 相互矛盾 等），或同一展项出现两个不同年份
  （含中文数字，如"一八五零年"），视为来源冲突。

## 仍需人工补充的项

以下信息系统无法自动获得，必须由项目负责人在真实项目中填写：

- 客户名称与对接人、资料授权范围与期限；
- 资料来源文件与页码/段落定位；
- 使用范围、禁用内容、交付格式、截止日期；
- 未决问题与责任人。

> demo 模式下本文件与其余六个文件都会带 DEMO 水印，不可作为客户交付。

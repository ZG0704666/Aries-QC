# 怀柔机器人产线动作采集规范 v2

## 1. 项目

怀柔机器人产线动作采集，交付方为数据服务商，验收方为机器人企业算法团队。

## 2. 标签类别与判定标准

| 类别 | 判定标准 | 最少实例数 |
|---|---|---|
| agv | 自主移动搬运车（AGV）车体，含车头、车斗与可见轮组；排除地面反光、地面标线、人物、叉车、普通货车 | 220 |
| robotic arm | 产线机械臂本体，含底座、连杆与末端执行器；排除机械臂线缆、控制柜、围栏、单独放置的工件 | 320 |
| rail door | 轨道门/滑轨门体，含门扇与可见轨道；排除普通木门、卷帘门、仅有地面轨道而没有门体的画面 | 240 |

## 3. 采集要求

- 本批次图像总量不少于 300 张。
- 单张图像分辨率不低于 720×720。
- 场景配额：AGV 小车不少于 120 张；供电柜联通测试不少于 100 张；轨道门缺陷识别不少于 110 张。
- 模糊图像比例不得超过 20%。

## 4. 标签格式

交付 YOLO 格式的分割多边形（segmentation），每个实例一行，类别 ID 从 0 开始连续编号。

## 5. 质检与交付

- 人工抽检比例 10%，P0 问题全量复核。
- 验收标准：P0 清零，P1/P2 候选逐条裁定，覆盖率不低于 90%。
- 工时基准：标注 80 框/人时，复核 250 框/人时，自动质检 200 图/人时。
- 交付周期 3 天。
